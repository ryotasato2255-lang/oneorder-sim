# 資金計画シミュレーション

新築注文住宅の総事業費と住宅ローン返済を、その場で試算するツールです。

## 使い方

- 「建物」で階数・延床面積・坪単価、「外構・解体・その他工事」で工事費、「土地・自己資金」で残りを入れると、他の項目は自動計算します
- 外構・解体・地盤改良・付帯工事・全館空調・仮住まいは、かんたん入力のままボタンで選べます
- 坪単価は100万円から10万円きざみで選べます（横スクロール）。階数を選ぶと目安が入ります
- 金額を直接入力した項目は「手入力」となり、自動計算より優先されます
- 「お客様に見せる」で、入力欄を隠した提示用の画面に切り替わります
- 入力内容は端末のブラウザ内（localStorage）にのみ保存されます。サーバーには送信されません
- 機種変更やPCとの受け渡しは「保存」タブのJSON書き出し・読み込みを使います

## 自動計算の考え方

| 項目 | 計算 |
|---|---|
| 主体工事費 | 延床坪数 × 坪単価（目安：平屋150／2階建て130／3階建て140 万円/坪。100〜300万円から選択可） |
| 追加変更の予備費 | 本体工事費 × 5% |
| 設計料 | （主体＋付帯＋全館空調）× 2.5%（BIM等は3.0%） |
| 工事監理費 | 同上 × 0.5% |
| 敷地調査・構造計算料 | 延床㎡ × 2,500円 |
| 不動産仲介手数料 | 土地代 × 3% ＋ 6万円 ＋ 消費税 |
| ローン事務手数料 | 借入額 × 2.2%（1.1%・定額・なしも選択可） |

単価の初期値は「くわしく調整」→「自動計算の基準」で変更でき、端末に保存されます。

## 注意

概算の試算です。金利・諸費用・税額は金融機関の商品内容やご契約条件により変動します。
正式な返済額は金融機関の審査結果に基づきます。

## 構成

単一のHTMLファイル（`index.html`）のみ。外部ライブラリ・Webフォントへの依存はありません。
