# 資金計画シミュレーション

新築注文住宅の総事業費と住宅ローン返済を、その場で試算するツールです。

## 使い方

- 入力は1画面です。階数・延床面積・坪単価を入れると、他の項目は初期値で自動計算します
- 金額はボタンで選ぶか、直接入力します。触った項目だけが「手入力」に変わり、自動計算より優先されます
- 坪単価は100万円から10万円きざみで選べます（横スクロール）。階数を選ぶと目安が入ります
- 金額を直接入力した項目は「手入力」となり、自動計算より優先されます
- 「お客様に見せる」で、入力欄を隠した提示用の画面に切り替わります
- 入力内容は端末のブラウザ内（localStorage）にのみ保存されます。サーバーには送信されません
- 機種変更やPCとの受け渡しは「保存」タブのJSON書き出し・読み込みを使います

## 項目の構成

| # | 項目 | 初期値 |
|---|---|---|
| 1 | 主体工事費 | 延床坪数 × 坪単価 |
| 2 | 付帯工事費 | 300万円 |
| 3 | エアロテック（全館空調） | 250万円 |
| 4 | 太陽光発電 | 30万円 |
| 5 | RC・地下工事 | 0 |
| 6 | 諸費用（設計・監理／構造計算・敷地調査／申請） | 自動計算 |
| 7 | 外構工事 | 0 |
| 8 | 解体工事 | 0 |
| 9 | 引込み工事 | 0 |
| 10 | 地盤改良工事 | 0 |
| 11 | 照明・カーテン | 200万円 |
| 12 | その他の費用（火災保険／登記／祭事／その他） | 自動計算 |
| 13 | ローン事務手数料 | 計上しない |
| 14 | 土地・自己資金 | 0 |
| 15 | 住宅ローン | 35年固定1.82%／35年 |

金額はボタンで選ぶか、直接入力します。空欄のままなら初期値で計算します。

## 自動計算の考え方

| 項目 | 計算 |
|---|---|
| 主体工事費 | 延床坪数 × 坪単価（目安：平屋150／2階建て130／3階建て140 万円/坪。100〜300万円から選択可） |
| 追加変更の予備費 | 本体工事費 × 5% |
| 設計・監理費 | （主体＋付帯＋エアロテック）× 3.0%（設計2.5%＋監理0.5%。BIM等は設計3.0%を選択） |
| 構造計算・敷地調査費 | 延床㎡ × 2,500円 |
| 不動産仲介手数料 | 土地代 × 3% ＋ 6万円 ＋ 消費税 |
| ローン事務手数料 | 初期は計上なし（借入×2.2%／1.1%／定額11万円も選択可） |

単価の初期値は画面下の「自動計算の基準」で変更でき、端末に保存されます。

## 注意

概算の試算です。金利・諸費用・税額は金融機関の商品内容やご契約条件により変動します。
正式な返済額は金融機関の審査結果に基づきます。

## 構成

単一のHTMLファイル（`index.html`）のみ。外部ライブラリ・Webフォントへの依存はありません。
